# Orhon'un Zotero Paneli / Orhon's Zotero Dashboard

_Orhon'un Zotero Paneli, Zotero kütüphanenizi web arayüzünden koleksiyon, öğe, PDF, not ve etiket düzeyinde yönetmenizi sağlar. Ayrıca Claude/Codex/Gemini CLI ve zotero-mcp entegrasyonuyla hızlı AI analiz üretir, çıktıları Zotero ve Obsidian’a senkronize eder._

**Orhon's Zotero Dashboard lets you manage your Zotero library from a web interface at the collection, item, PDF, note, and tag level. It also uses Claude/Codex/Gemini CLI with zotero-mcp to generate fast AI analysis and sync results to both Zotero and Obsidian.**
